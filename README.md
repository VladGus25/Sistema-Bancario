# Sistema Bancário

Este é um projeto de um **Sistema Bancário** desenvolvido em Java. A aplicação simula operações bancárias essenciais, permitindo o gerenciamento de contas e transações de forma simples e estruturada.

O projeto foi desenvolvido como parte de atividades práticas para consolidação de conceitos de Programação Orientada a Objetos (POO) e manipulação de fluxos de dados.

---

## Tecnologias Utilizadas

- **Java** (Linguagem principal)
- **NetBeans IDE** (Ambiente de desenvolvimento)
- **Git & GitHub** (Controle de versão)

---

## Funcionalidades Esperadas

- [x] Criação e gerenciamento de contas bancárias.
- [x] Operações de depósito e saque com validações de saldo.
- [x] Consulta de saldo e extrato.
